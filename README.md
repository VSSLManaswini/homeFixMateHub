# HomeFix

All-in-one home & local services landing page. Find, compare, book, and list verified providers.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview the production build

## First place to change

- Provider / receiver onboarding: `src/components/RoleGate.tsx`
- Service categories: `src/data/categories.ts`
- Brand colors & theme tokens: `src/index.css`
